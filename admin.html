티켓 DB 생성 도구 (운영자용)

명단 엑셀을 이 페이지에 올리면 암호화된 db.json과 스태프 확인용 명단이 만들어집니다. 모든 처리는 이 브라우저 안에서만 이루어지며, 어떤 서버로도 명단이 전송되지 않습니다.

1. 명단 엑셀 준비

첫 행이 제목인 엑셀(.xlsx)로, 열 이름은 이름 연락처 구역 좌석 (선택: 등급) 을 사용하세요. 같은 사람의 좌석이 여러 개면 행을 여러 줄로 나눠 적으면 됩니다. 양식: tools/명단_양식.xlsx

2. 변환

3. 적용

  1. 내려받은 db.json으로 GitHub 저장소의 data/db.json을 교체(업로드)합니다.
  2. 배포가 갱신되면(약 1분) 관람객이 이름+연락처 뒤 4자리로 티켓을 조회할 수 있습니다.
  3. 스태프 확인용 명단은 입장 스태프에게만 전달하세요. 확인코드가 들어 있습니다.

※ 원본 명단 엑셀과 스태프 확인용 명단은 개인정보가 담겨 있으니 GitHub에 올리지 마세요 (.gitignore로 기본 차단됨).
※ 동명이인이 연락처 뒤 4자리까지 같은 경우 자동으로 감지해 알려드립니다.
