초대 티켓 확인

초대 안내를 받으신 이름과 연락처 뒤 4자리를 입력하면 티켓이 표시됩니다.

입장 시 캡처 화면이 아닌 실시간 화면을 제시해 주세요.
(초 단위 시계가 움직여야 유효한 티켓입니다)

관리자 로그인

운영자용 티켓 DB 생성 도구입니다. 비밀번호를 입력해 주세요.

티켓 DB 생성 도구

명단 엑셀을 올리면 암호화된 db.json과 스태프 확인용 명단이 만들어집니다. 모든 처리는 이 브라우저 안에서만 이루어지며, 어떤 서버로도 명단이 전송되지 않습니다.

열 이름: 이름 연락처 구역 좌석 (선택: 등급) · 같은 사람의 좌석이 여러 개면 행을 여러 줄로 입력 · 양식: 명단_양식.xlsx

  1. 내려받은 db.json으로 저장소의 data/db.json을 교체하면 약 1분 뒤 반영됩니다.
  2. 스태프 확인용 명단은 확인코드가 들어 있으니 입장 스태프에게만 전달하고, GitHub에는 올리지 마세요.
문의는 초대 안내를 드린 담당자에게 부탁드립니다.
