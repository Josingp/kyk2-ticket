관리자 로그인

티켓 DB 생성 도구

명단 엑셀을 올리면 암호화 후 서버 DB에 바로 적용됩니다. (재배포 불필요, 즉시 반영) 명단 원본은 서버 저장소(Upstash)에만 보관되고, 공개 DB에는 암호문만 올라갑니다.

열 이름: 대분류 소분류(동반인·선택) 연락처 구역 좌석 (선택: 등급) · 조회는 대분류+연락처 뒤 4자리로 하며, 소분류가 있으면 티켓에 대분류 (소분류)로 표기됩니다 · 같은 사람의 좌석이 여러 개면 행을 여러 줄로 · 양식: 명단_양식.xlsx

  1. 업로드 즉시 서버에 적용됩니다. 자동 적용이 실패하면 db.json을 내려받아 저장소의 data/db.json을 교체하세요. (백업 경로)
  2. 스태프 확인용 명단은 확인코드가 들어 있으니 입장 스태프에게만 전달하고, GitHub에는 올리지 마세요.
